Client-side third parties

  • Google Analytics (gtag) - hardcoded ID G-H52D8T9BX8
  • Google Fonts - Inter and talents CSS
  • OpenStreetMap tiles - transport maps and stop picker (free, tile usage policy limits heavy use)
  • YouTube (nocookie) - embedded videos in study materials
  • Razorpay and Cashfree checkout SDKs from their CDNs

Mobile apps (SMS Mobile)

  • Sentry - crash reporting (EXPO_PUBLIC_SENTRY_DSN)
  • Expo / EAS - builds and push
  • Apple Developer and Google Play accounts for store releases
  • Firebase/FCM and APNs - reached through Expo push, not direct SDKs
  • LiveKit client and react-native-razorpay

Leftovers

  • amplify/ (AWS Amplify) is the stock scaffold; nothing from AWS is actually used.
  • WhatsApp notification for landing-page leads (LEAD_NOTIFY_WHATSAPP) is only a logging stub.
  • SMTP_USERNAME defaults to a real Brevo login in compose files; consider moving it into .env.

Minimum paid set for a real launch

  • Azure SQL, Azure Blob Storage, a VM with domain and wildcard DNS, Brevo
  • An SMS provider (MSG91 or Twilio) if OTP is enabled
  • An AI provider key if real AI is wanted instead of Mock
  • Razorpay if online fee payment is wanted
  • Apple and Google developer accounts, and Sentry, for the mobile apps
