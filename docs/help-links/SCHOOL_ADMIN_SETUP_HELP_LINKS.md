# School Sphere: Help Center links for school admin first-time setup

Base URL: `https://sms-schoolsphere.com`
- Article link: `/help/a/<article-id>`
- Module page (all articles of a module): `/help/m/<module-id>`
- Role page: `/help/r/<role>`
- Help Center home: `/help` (also `/guide`)

Links are built from the article ids in `docs/help/modules/*` and the module ids in `src/app/routeRegistry.ts`.
Every topic below has its own article except those listed under Remaining gaps.
