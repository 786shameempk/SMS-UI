1. Open the **Account menu** and choose **My attendance pass**. The page shows an **Attendance QR pass**.
2. Hold the screen up so your teacher or the gate scanner can read it: "Show this to your teacher or at the gate."
3. The code changes every minute and works once. The page shows "Refreshes in ...s". Select **New pass now** if it was already used or has expired.

If you see "No attendance pass", your account is not set up for QR attendance; ask the school. Select **Try again** if the pass could not be loaded.

The same pass is in the School Sphere mobile apps. A screenshot will not work for long because the code keeps changing.
