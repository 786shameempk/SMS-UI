Anyone who is the approver for other people's profiles (a class teacher, department head, reporting person or the office) sees **Profile approvals** in the **Account menu**.

1. Open **Profile approvals**. It lists the requests assigned to you. If there are none you see "Nothing is waiting for you".
2. Use **Search by name** to find a request.
3. Select **View details**. The **Profile change** shows who it is **Requested by**, and for every **Field** the **Current** value next to the **Proposed** one.
4. Select **Approve** to apply it ("Approved. The profile has been updated."), or **Reject** ("Rejected. The profile was not changed."). A **Comment** is required to reject, so the person knows why.

Nothing changes on a profile until you approve. The **History** shows requests that were already decided.

> **Note:** Changes to a name or date of birth are decided by the school's office, not by class or department approvers.
