Mobile code sign-in only works for a number you have verified yourself. A number typed in by an administrator stays **Not verified** until you confirm it here.

## Steps

1. Select your avatar at the top right and choose **Security settings**.
2. Stay on the **Password** tab and find the **Mobile number** card. A badge shows **Verified** or **Not verified**.
3. Type your number in **Mobile number** (or **New mobile number** if one is already on file) and select **Send code**. Start with the country code if you are outside the school's country.
4. Type the six-digit code from the text message into **Verification code**.
5. Select **Verify number**. "Mobile number verified" appears and the badge changes to **Verified**.

Didn't get the code? Select **Resend code** when the countdown ends, or **Change number** to start again with another number.

## Good to know

- Changing your mobile number resets it to **Not verified** until you confirm the new one.
- The card shows your number partly hidden, for example the last digits only.
- If the school has not turned on code sign-in, sending a code is refused. Ask your administrator.
