Use this to record attendance for school staff.

## Steps

1. Open **Attendance** and select the **Staff Attendance** tab.
2. Pick the date.
3. Select **Mark all present** if most people were in, then change the exceptions. The statuses are **Present**, **Absent** and **Late**.
4. Select **Save attendance**.

A "Staff attendance saved" message confirms it. If it fails you see "Could not save staff attendance". If the school has no staff to list, the page says "No staff to mark attendance for."
