Every student, staff member and record belongs to one branch.

## Steps

1. Open **Branch Management** from the menu. The page is headed **Branch management**.
2. Select **Add branch**.
3. Enter the **Branch name** and a **Short code**. Both are required ("Name is required", "Code is required").
4. Optionally enter the **Address** and **Phone**, and set the **Status** (active or inactive).
5. Choose what **Classes teachers see in the mobile app**.
6. Select **Add branch** ("Branch added").

To change a branch, edit it, change the details and select **Save changes** ("Branch updated"). Deleting a branch shows a message with its name.
