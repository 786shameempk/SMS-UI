## Record

1. Open **Extra-Curricular**, then **Achievements**, and select **Record an achievement**.
2. Choose the **Student**, give a **Title**, and optionally the **Award**, **Level**, date, description and a link to a supporting document.
3. Select **Record**. It starts as **Awaiting approval** and is private.

## Publish

Someone with approval rights selects **Publish** (or **Reject**). Only published achievements appear for parents and students. A published achievement cannot be edited or deleted until it is unpublished.
