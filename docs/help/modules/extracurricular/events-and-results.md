## Create an event

1. Open **Extra-Curricular**, then **Events**, and select **New event**.
2. Enter the **Name**, the **Kind of event** (for example Sports Day), the dates, **Register by**, **Level**, venue and organiser.
3. Set **Status**. Families only see events that are no longer **Draft**, and can register only while it is **Registration open** and before the deadline.

## Register

Select **Register** on an event, choose a student (staff can also choose a team or a group) and register. A parent can register only their own child. **Withdraw** removes a registration while registration is open.

## Record results

1. Select **Results** on the event.
2. Select **Add registered participants** or **Add a row**.
3. Enter the **Round**, **Score**, **Rank** and **Award**.
4. Leave **Rank by score when no rank is given** ticked to rank by score, highest first.
5. Select **Save results**. Saving a round replaces that round's results. Two participants cannot share a rank in a round.
