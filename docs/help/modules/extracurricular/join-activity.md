## Ask for a place

1. Open **Extra-Curricular** and select **Activities**.
2. Search, or pick a **Category**, or select **Open for enrollment** to see only what you can join now.
3. On the activity, select **Ask to join**. If the activity is full the button says **Join waiting list**.
4. Choose the **Student** (a parent with one child sees them already selected).
5. If the activity needs it, tick the parental consent line. Read any safety notice shown.
6. Add a **Note** if you want, then select **Send request**.

The message tells you what happened: **Request sent** (waiting for approval), **Enrolled**, or **Added to the waiting list**.

## Follow it up

Open **Enrollments** to see each request and its status: Requested, Approved, Waiting list, Rejected, Withdrawn or Completed. Select **Withdraw** to give a place back; the next student on the waiting list takes it.

> **Note:** The button is greyed out when the activity is not active or its enrollment dates have passed. Some schools turn off requests from families; then the office or the teacher enrolls students and you will see a message saying so.

## Why a request can be refused

- The student is outside the grades the activity is open to.
- The student already has a request or place in it, or is at the school's limit of activities.
- Parental consent is required and was not ticked.
- Approval would put the student in two sessions at the same time.
