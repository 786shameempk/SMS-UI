Teams belong to an activity. You can have as many as you need for the same sport, such as age groups, levels, boys', girls' or mixed. Create the activity first in [Create activities and categories](help:extracurricular-activities).

## Create a team

1. Open **Co-Curricular** and select **Teams**.
2. Select **New team**.
3. Choose the **Activity** and enter the **Name**, and a **Code** if the school uses one.
4. Optionally add a **Level or category** (for example Under 14, Beginner, Girls or Mixed), a **Coach**, a **Colour** and a **Squad size limit**.
5. Leave it **Active**, then select **Create team**.

Use **Edit** to change a team later. **Delete team** removes it. Former members are kept as history.

## Add players

1. On the team, select **Add a player** and choose a **Student**. Only students enrolled in the activity can join.
2. Set the **Role** (for example **Captain**), the **Position** and the **Jersey number**.
3. Tick **Substitute (not counted against the squad limit)** for a reserve.
4. Select **Add to team**.

**Remove** takes a player out of the squad. **Transfer…** moves a player to another team.
