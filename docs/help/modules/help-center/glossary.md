| Term | Meaning |
|---|---|
| **Branch** | A campus of your school. Users can be limited to one branch, or allowed to switch between all of them. |
| **Role** | A set of permissions given to users, such as Teacher or Accountant. Schools can also create their own. |
| **Permission matrix** | The grid under **Roles & Permissions** that decides which modules and actions each role has. |
| **Module** | One area of the application, such as Students or Fee Management. Your school's plan decides which are switched on. |
| **Academic year** | The school year that classes, fees and exams belong to. Set up under **Academic Setup**. |
| **Term** | A part of an academic year. |
| **Class and section** | A class (for example Class 5) is divided into sections (for example A and B). Students belong to a section. |
| **Guardian** | A parent or other adult recorded on a student's profile. A guardian can be linked to a login so they see the child in the Parent Portal. |
| **Linked login** | The link between a student, guardian or staff record and the sign-in account that belongs to them. |
| **Admission** | The process from a new application to an enrolled student. |
| **Promotion** | Moving a class's students to the next class at the end of a year. |
| **Fee structure** | The amounts a class pays, by type and how often. Invoices are generated from it. |
| **Invoice** | A bill for one student for one term. Payments are recorded against it. |
| **Receipt** | The record produced when a payment is recorded. |
| **Payroll run** | A calculation of staff salaries for a period, which produces payslips. |
| **Question bank** | Reusable questions that online exams are built from. |
| **Online class** | A live class or meeting held inside School Sphere. |
| **Ticket** | A complaint or request in the Help Desk. |
| **Ask School AI** | The assistant that answers questions about your school's data, and about how to use School Sphere. |
