Only administrators and principals see **Post announcement**.

1. Select **Post announcement**. The dialog says it shows up in the in-app notification inbox for the chosen audience.
2. Enter a **Title** and **Message** (both required: "Title is required", "Message is required").
3. Choose the **Category** and the **Audience**: **Everyone**, **Admins**, **Principal**, **Teachers**, **Accountants**, **Librarians**, **Receptionists**, **Parents** or **Students**.
4. Optionally add a **Link**.
5. Select **Post announcement** ("Announcement posted").
