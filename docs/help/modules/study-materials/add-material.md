Teachers and the platform administrator see **Add material**. Other roles can browse only.

1. Select **Add material**.
2. Enter a **Title** (up to 200 characters) and choose the **Material type**: Notes, Textbook / E-book, Worksheet, Assignment, Question paper, Previous year paper, Answer key, Video, Presentation or Reference.
3. Optionally add a **Chapter / topic** and a **Description**.
4. Choose the **Class** and **Subject**, and who can see it: **All students**, **One class** or **One section** (a class, or a class and section, is then required).
5. Under **File or link**, attach a file (PDF, Word, PowerPoint, Excel, images, ZIP or text, up to the size shown) or add a link for a video. One of the two is required: "Attach a file or add a video/external link."
6. Select **Save as draft**, or **Publish** to share it with students ("Saved as draft" or "Material published").

If the file type is not supported you see "That file type isn't supported. Use PDF, Word, PowerPoint, Excel, images, ZIP or text."

## Your own materials

The **My materials** tab lists what you uploaded. For the platform administrator it is the **Platform library**, shared with every school. A school's uploads stay inside that school.
