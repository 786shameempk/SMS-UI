# 4. Interface languages and right-to-left

English, Malayalam, Hindi, Tamil and Arabic (right-to-left). Conventions for writing translatable screens: [i18n-guide.md](i18n-guide.md).

## What exists

| Piece | Where |
|---|---|
| Library and lazy loader (one JSON file per language and namespace) | `src/i18n/index.ts`, `src/i18n/locales/<lng>/<namespace>.json` |
| Language list, direction, locale, Noto font per script | `src/i18n/languages.ts` |
| Picker in the account menu | `src/i18n/LanguageMenu.tsx` |
| Account preference (own choice, else the school default from Settings → Localization) | `src/i18n/preferences.ts`, AuthService `GET /api/account/preferences`, `PUT /api/account/preferences/language` |
| `<html lang dir>` set before first paint; physical Tailwind classes replaced by logical ones; chevrons mirrored | `src/main.tsx`, `src/index.css` |
| Dates, numbers, money follow the language | `src/utils/format.ts` |

## Translated modules (ml, hi, ta, ar)

Shell and navigation, common components (tables, dialogs, import, pagination, command menu), authentication and security, notifications, calendar, attachments, dashboard, settings, administration, students, accounting, fees, payroll, staff, teachers, health, hostel, inventory, library, transport, visitors, certificates, help desk, surveys, online exams, AI features, Help Center, reports, communication, timetable, homework, academics, extracurricular, lesson-portions, attendance, parent-portal, study-materials, examinations, talents and meetings.

The school-facing landing page (`marketing`, public sales copy) is deliberately left in English.

## Known gaps

* The last twelve modules were converted with a script (JSX text, common attributes such as placeholder/title/label, toast messages, table headers) and then type-checked and tested. Strings it could not reach stay English: text in module-level constants and helper functions outside components, and error messages thrown from api files. Option labels from `constants.ts` are translated where a component renders `X.label`.
* A few sentences are assembled around a link or an inline element (for example in lesson-portions Resources and Settings, and the attendance device-key help). Their parts are translated separately, so word order can read awkwardly in some languages.
* The internal consoles (office, platform, azure-dashboard) are still English.
* All translations were drafted by an AI model and need native-speaker review.

## Checking it

* `npx vitest run src/i18n` fails if a language is missing a namespace, a value is empty, or a translation changes the `{{placeholders}}` of its English key.
* Translations were drafted by an AI model and need a native-speaker review before being called official.
* Unit tests for the account preference endpoint: AuthService `AccountPreferencesHandlerTests` (9 tests).
